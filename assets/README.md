# SvaraHome artwork

SvaraHome belongs to the same visual family as GivHome: a rounded-square tile and layered house, with a turquoise three-bladed fan replacing the GivHome letter.

Brand blue: `#026AB3`. The house uses layered cool blues, clear roof eaves and restrained highlights. The fan remains legible within a white circular face. The app/plugin icon carries no text so it reads at small sizes.

- `svarahome-master.png`: selected full-size generated artwork.
- `svarahome.png`: 1024 × 1024 project icon.
- `homebridge-pax-calima.png`: 100 × 100 PNG for the existing npm package’s Homebridge icon request.

The original supplied GivHome image and the two SvaraHome drafts remain untouched in the owner’s files. This icon was produced with the built-in image generation tool; the final prompt is saved in `docs/BRANDING.md`.

Homebridge maintains plugin icons centrally. Submit the small icon with verification, or request its registration after verification. The artwork does not imply manufacturer endorsement or Homebridge verification.
