## Historical evidence

[BETA1-LIVE-DIAGNOSTIC.md](BETA1-LIVE-DIAGNOSTIC.md), the [redacted control records](pi-live-control-evidence-20261025.jsonl), dependency audits, native-install records, TAP logs and package manifests are snapshots from specific builds and investigations. Their filenames, test counts and earlier acceptance gaps describe those checks at that time; they are not the current user guide or guarantees about every fan.

The current validation summary takes precedence when assessing present coverage. Prior published packages and release copy remain available through their immutable tags and GitHub prereleases. Preserve evidence; do not copy the investigation narrative into user-facing release notes.
